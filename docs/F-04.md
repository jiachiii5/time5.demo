# 功能設計：F-04 查找與索引系統

本計畫文件旨在設計代號 **F-04** 的「查找與索引系統」，包含時間軸搜尋與關鍵字檢索兩大核心功能。

## 1. 系統目標
允許使用者根據特定時間區間以及自訂關鍵字，從系統中快速篩選並找出所需資料。

## 2. 功能需求

### 2.1 關鍵字檢索 (Keyword Search)
* **行為**: 使用者在搜尋框輸入關鍵字後，系統會在資料庫的「標題 (Title)」與「內容 (Content)」中進行模糊比對 (LIKE)。
* **目的**: 讓使用者能夠快速找到包含特定字詞的記錄。

### 2.2 時間軸搜尋 (Timeline Search)
* **行為**: 使用者可以指定一個「起始時間」與「結束時間」（或單一指定），系統將過濾出「建立時間 (Created At)」在此區間內的記錄。
* **目的**: 讓使用者能夠針對特定時間範圍進行資料調閱。

### 2.3 複合查詢 (Combined Search)
* **行為**: 同時支援關鍵字與時間軸的複合條件篩選。

---

## 3. 系統設計建議 (System Design Proposal)

### 3.1 前端與 UI 設計
**新增搜尋區塊元件**
* 一個輸入框 (Input Text) 提供關鍵字輸入。
* 兩個日期選擇器 (Datepicker) 分別提供「開始時間」與「結束時間」。
* 一個「搜尋」按鈕與一個「清除條件」按鈕。

### 3.2 API 設計 (Backend)
**新增搜尋 API 端點**
* **Endpoint**: `/api/search` 或 `/search`
* **Method**: `GET`
* **Query Parameters**:
  * `q` (字串, 選填): 關鍵字
  * `start_date` (日期/時間, 選填): 起始時間 (格式例如 `YYYY-MM-DD`)
  * `end_date` (日期/時間, 選填): 結束時間 (格式例如 `YYYY-MM-DD`)
* **Response**: 回傳符合條件的資料列表 (JSON 或直接渲染 Jinja2 模板)。

### 3.3 資料庫設計 (DB Design)
**目標資料表查詢邏輯 (SQLite)**
核心查詢邏輯參考：
```sql
SELECT * FROM <target_table>
WHERE 
    (title LIKE '%<keyword>%' OR content LIKE '%<keyword>%')
    AND (created_at >= '<start_date>' OR '<start_date>' IS NULL)
    AND (created_at <= '<end_date>' OR '<end_date>' IS NULL)
ORDER BY created_at DESC;
```
*(如果需要提升檢索效能，可以考慮為 `created_at` 建立 Index，或針對大文本使用 SQLite 的 FTS5 擴充模組)*

## 4. 驗證計畫
1. 準備測試資料集（包含不同的建立日期與特定關鍵字的內容）。
2. 在 UI 上輸入「單一關鍵字」，確認檢索結果。
3. 在 UI 上選擇「特定時間區間」，確認能正確過濾資料。
4. 結合「關鍵字 + 時間區間」進行複合查詢，確認過濾結果的交集精確度。
5. 點擊「清除條件」，確認畫面與結果列表能重置。
