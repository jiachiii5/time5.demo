# PRD 產品需求文件：數位時光膠囊 (Digital Time Capsule)

## 1. 專案概述
### 1.1 動機與背景
在步調快速的現代社會中，人們經常因為忙碌而忘記了當下的初衷、情緒或對未來的期許。傳統的紙本信件容易遺失或損壞，且缺乏互動性。因此，我們希望透過「數位時光膠囊」系統，讓使用者能安全地封存當下的文字與心情。這不僅是一個紀錄工具，更是一種與「未來的自己」跨時空對話的方式，在特定時間點解鎖時，提供情緒價值與自我反思的機會。

### 1.2 目標用戶
- 熱愛記錄生活的任何人
- 追求視覺與美感的統一
- 需要碎片化紀錄與多模態整合
- 尋求回顧與發現的驚喜感

### 1.3 核心價值主張與目標
- **目標一**：解決因為忙碌忽視生活中的美好瑣事，提供快速方便的紀錄管道。
- **目標二**：方便查找特定時間的回憶，隨時喚醒過去的記憶。
- **目標三**：建立有設計感的回顧圖片發至社群媒體，滿足分享與自我表達的渴望。

## 2. 功能需求

### 主要功能與使用者故事

1. **建立時光膠囊 (Create Capsule)**
   - 作為使用者，我希望可以輸入標題、內容、選擇當下心情（標籤），並設定未來的「解鎖日期」，以便將當下的心情與期許封存給未來的自己。


2. **時間鎖機制 (Time Lock)**
   - 作為使用者，我希望膠囊在到達指定日期前無法被開啟，以便體驗跨越時空對話的期待感與驚喜感。

3. **回憶清單與搜尋 (Memory List & Search)**
   - 作為使用者，我希望可以瀏覽所有已解鎖的膠囊，或透過日期、心情標籤快速查找，以便方便地尋找特定時間的回憶。

4. **美感回顧圖片生成 (Aesthetic Review Image Generation)**
   - 作為使用者，我希望解鎖後的膠囊能以具設計感的圖片形式呈現，以便我能將這些精美的回顧圖片分享至社群媒體。

5. **首頁儀表板 (Dashboard)**
   - 作為使用者，我希望在首頁能看到即將解鎖的倒數計時以及心情統計，以便隨時掌握我的封存狀態與情緒變化。

## 3. 非功能需求

### 技術限制
- 後端框架：Flask (Python)
- 模板引擎：Jinja2
- 資料庫：SQLite (適合輕量化存儲)
- 前端技術：HTML, CSS (強調視覺與美感的統一，可能考慮現代化 CSS 框架或手刻美觀 UI)


### 非功能性需求（Non-functional Requirements）
- **效能**：倒數計時器需在前端精準顯示、頁面載入時間需小於 3 秒。
- **安全性**：使用者密碼需經過雜湊（Hash）加密儲存；後端需有路由保護，防止使用者透過修改 URL 提早偷看膠囊內容。
- **易用性**：多台裝置同步，確保在手機或電腦上都能清楚閱讀與操作（包含響應式設計 RWD）。

### 範圍限制（Out of Scope）
為了避免專案範圍過度膨脹，本次專題**不包含**以下項目：
- **複雜的內容與容量限制**：不實作如「影片限制 30-60 秒」或「照片限制一天 5 張」等精細的系統檢查機制。
- **實名認證與進階帳號安全**：不提供實名認證系統或法律免責條款。系統僅提供基礎帳號註冊與登入，不負責驗證使用者真實身份。
- **專業音訊與媒體編輯**：僅提供基礎的錄音與播放功能，不包含混音、後製濾鏡或進階媒體剪輯工具。

## 4. MVP 範圍

### Must Have (必備功能)
- 建立文字時光膠囊（包含標題、內容），並選擇解鎖日期。
- 膠囊清單列表與狀態顯示 (包含倒數計時/未解鎖/已解鎖)。
- 時間鎖邏輯 (未到期前隱藏真實內容)。
- 解鎖並閱讀膠囊。

### Should Have (期望功能)
- 心情標籤功能與清單過濾。
- 自動生成可供分享的精美回顧圖片 (例如特殊設計的卡片版面)。
- 基本的首頁數據概覽 (封存總數、即將解鎖提示)。

### Nice to Have (加分功能)
- 多模態紀錄 (上傳圖片/錄音)。
- 社群分享按鈕 (一鍵下載圖片或分享到 IG/FB)。
- 每日反思提醒 (例如簡單的 Web 提醒)。
